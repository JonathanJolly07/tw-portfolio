A centralized repository containing technical documentation, scientific typeset documents, presentation slide decks, and version control procedures completed for the **Technical Writing** course at **MNIT Jaipur**.

---

## Portfolio Modules

| Module | Topic | Description | Source & Output |
| :--- | :--- | :--- | :--- |
| **01. Git & GitHub** | Version Control | Command references, branching, merging, and PR workflows | [Documentation](./docs/git/README.md) |
| **02. LaTeX** | Scientific Typesetting | Academic report structure, math formulas, and compiling | [Source & PDF](./docs/latex/) |
| **03. Beamer** | Presentations | Structured slide decks, themes, and Beamer frames | [Source & PDF](./docs/beamer/) |
| **04. Doxygen** | Code Documentation | Tagging standards (`@brief`, `@param`), config files, and HTML output | [Source & Guide](./docs/doxygen/) |
| **05. Google Docs** | Collaborative Writing | Styles, headings, peer-review comments, and exporting | [Guide](./docs/googledocs/README.md) |
