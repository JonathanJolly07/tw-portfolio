\section{Scientific Typesetting}
\begin{frame}{Structured Authoring with \LaTeX{} \& Beamer}
  \begin{block}{Why Plain-Text Typesetting?}
    Separating document logic from visual layout ensures consistent formatting across research papers and presentations.
  \end{block}
  \vspace{0.2cm}
  \begin{itemize}
    \item \textbf{Mathematical Precision:} Native rendering for complex equations such as $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$.
    \item \textbf{Automated Indexing:} Dynamic Table of Contents, cross-references, and Bib\TeX{} citations.
    \item \textbf{Beamer Decks:} Modular frames, themes, and structured visual blocks.
  \end{itemize}
\end{frame}
