# Google Docs: Collaborative Technical Writing

## Key Concepts Learned
- **Heading Hierarchy:** Structuring documents using Title, Subtitle, Heading 1, and Heading 2 to automatically generate dynamic Tables of Contents.
- **Collaborative Review:** Using Suggesting Mode, threaded comments, and @mentions for peer review.
- **Academic Standards:** Inserting cross-page footnotes, image captions, and tables with consistent padding.
- **Document Portability:** Exporting documents to clean .pdf formats while preserving hyperlink anchors.
