# Google Docs: Collaborative Technical Writing

## Key Concepts Learned
- **Semantic Heading Hierarchy:** Structuring documents using `Title`, `Subtitle`, `Heading 1`, and `Heading 2` styles to automatically generate dynamic Tables of Contents and outline navigation.
- **Asynchronous Peer Review:** Using **Suggesting Mode** for tracked edits, anchored comment threads, and `@mentions` to assign action items.
- **Academic & Technical Standards:** Inserting cross-page footnotes, numbered figure/table captions, and clean tables with consistent cell padding.
- **Archival Portability:** Exporting final deliverables to `.pdf` format while preserving internal bookmark links and external hyperlinks.
